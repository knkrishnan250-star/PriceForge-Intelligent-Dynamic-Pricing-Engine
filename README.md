 PriceForge – Dynamic Pricing Engine

AI-ready dynamic pricing engine built using FastAPI.

Features
- Rule-based pricing
- Demand adjustment
- Stock-based surge
- Time-based pricing
- SQLite database
- Modular architecture

## Run Project

pip install -r requirements.txt
uvicorn backend.main:app --reload

Visit:
http://127.0.0.1:8000/docs
